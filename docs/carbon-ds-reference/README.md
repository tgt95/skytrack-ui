### 1. [Foundations & IBM Design Language (Elements)](elements/)
Foundational visual rules and design tokens:
- **[2x Grid](elements/2x-grid/overview.md)**: 16-column layout grid, margins, gutters, breakpoint specifications.
- **[Color](elements/color/overview.md)**: Full color palette, theme architecture (White, Gray 10, Gray 90, Gray 100).
- **[Color Tokens](elements/color/tokens.md)**: Core UI tokens, contextual layer tokens, and component tokens.
- **[Typography](elements/typography/overview.md)**: IBM Plex Sans/Mono/Serif type scales, weights, and expressive heading hierarchies.
- **[Spacing](elements/spacing/overview.md)**: Fixed spatial scale (2px to 160px) and layout tokens.
- **[Motion](elements/motion/overview.md)**: Easing curves (productive vs expressive), durations, choreography.
- **[Themes](elements/themes/overview.md)**: Theme layering and semantic application.
- **[Icons](elements/icons/usage.md)** & **[Pictograms](elements/pictograms/usage.md)**: Visual iconography and pictogram standards.
