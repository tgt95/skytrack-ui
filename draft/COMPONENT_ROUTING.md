## Fast distinctions

| If you are choosing between… | Prefer… | When… |
| --- | --- | --- |
| Alert Dialog / Dialog | Alert Dialog | Confirmation is high impact or hard to reverse; use Dialog for a focused task without that confirmation role. |
| Accordion / Collapsible | Accordion | There are multiple related disclosures; use Collapsible for one optional panel. |
| Date Picker / Calendar | Date Picker | Date entry is a compact field; use Calendar for a standalone visible month grid. |
| Select / Radio Group / Combobox | Select | A fixed list is too long to show at once but does not need search; use Radio Group for a short visible set, Combobox for searchable constrained choices. |
| Autocomplete / Combobox | Autocomplete | Typing suggestions are primary and freeform text may be meaningful; use Combobox when a listed option must be selected. Verify each page's constraints. |
| Checkbox / Switch / Toggle | Checkbox | Selection is committed with a form; use Switch for an immediate setting, Toggle for a button-like pressed state. |
| Meter / Progress | Meter | The number is a measured value against a fixed range; use Progress for work completion. |
| Alert / Toast | Alert | The information should remain in context; use Toast for brief, non-blocking feedback. |
| Menu / Context Menu / Command | Menu | An explicit trigger opens a nearby action list; use Context Menu for pointer/long-press context, Command for searchable keyboard-oriented commands. |
| Tabs / Navigation Menu / Sidebar | Tabs | People switch independent panels of one context; use navigation components for distinct product destinations. |
| Data Table / Chart | Data Table | Exact record lookup or row-by-row comparison is primary; use Chart for quantitative patterns/comparison, with exact values available when required. |

## Package artifacts and export names

In the current `0.1.5` checkout, 43 component families have compiled files in `dist-lib`; these 8 declared subpaths are not present as built `.js`/`.d.ts` artifacts: `calendar`, `chart`, `command`, `data-table`, `date-picker`, `page-header`, `pagination`, and `sidebar`. The source files and manifest entries do not make these imports usable in a consumer app. Before using them there, check the installed package files. If missing, use supported available components or a justified semantic fallback and state the gap.

Developer knowledge snippets use the source showcase alias `@/components/ui/<slug>`. In a consumer app, translate that path only after verifying the public import and built artifact for the installed version. Component family names also differ from exported symbols: Checkbox uses `CheckboxRoot`; Fieldset uses `FieldsetRoot` and `FieldsetLegend`; Radio Group uses `RadioGroup`, `RadioRoot`, and `RadioIndicator`; Chart uses `ChartContainer`; Toast uses `ToastProvider`, `ToastRoot`, and `useToastManager`. Detached overlay handles use the subpath's `createHandle` where available; the root entry uses names such as `createDialogHandle` and `createAlertDialogHandle`. Verify the exact export in source and the installed declarations.

Calendar does not have a dedicated `calendar.demo.tsx`; its closest showcase example is the `CALENDAR` variant in `date-picker.demo.tsx`, with a synthesized showcase id. Match demos by content and installed version, not filename alone.
