# Multi-Pane / Three-Column Shell

> Three-column master-detail layout enabling rapid triage, search, and deep inspection without page context loss.

- Package version: `0.1.5`
- Showcase demo id: `multi-pane-shell`
- Closest demo: [`src/demos/multi-pane-shell.demo.tsx`](../../../../src/demos/multi-pane-shell.demo.tsx)

## Overview

Three-column architecture: Column 1 (Queues/Folders) -> Column 2 (Master List) -> Column 3 (Detail View).

## Usage

- Customer support service desks, CRM ticketing, and B2B communication tools.
- High-volume record triage and verification without navigating away from the list.

**Live demo variant:** `Default`
