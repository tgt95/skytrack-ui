# Workspace / Canvas-centric Shell

> Infinite visual canvas with docked toolbars and property inspector for nodal pipelines and visual editors.

- Package version: `0.1.5`
- Showcase demo id: `canvas-shell`
- Closest demo: [`src/demos/canvas-shell.demo.tsx`](../../../../src/demos/canvas-shell.demo.tsx)

import { CanvasShellMock } from '@/demos/canvas-shell.demo'

## Overview

Traditional chrome is reduced to slender toolbars, dedicating maximum screen space to an interactive canvas for drag-and-drop workflow modeling.

## Usage

- Workflow automation builders (n8n, Make), ETL data pipelines, and visual graph builders.
- Pairs visual diagram nodes with a docked inspector panel for configuration.

**Live demo variant:** `Default`
