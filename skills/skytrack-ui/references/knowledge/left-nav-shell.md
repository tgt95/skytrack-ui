## Overview

Left Navigation Shell is the primary architectural shell pattern for enterprise management systems. The persistent vertical sidebar provides hierarchical navigation and collapses cleanly to an icon rail.

## Usage

- Enterprise ERP, CRM, and Headless CMS applications.
- Supports multi-level menu structures (L1, L2, L3) and icon collapse.
- Maximizes orientation stability across deep operational routes.

**Live demo variant:** `Default`
