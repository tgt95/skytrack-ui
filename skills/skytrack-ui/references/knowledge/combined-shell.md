## Overview

The top bar functions as the strategic application switcher, while the left sidebar handles contextual task navigation within the active module.

## Usage

- Enterprise cloud suites (AWS, Azure, NetSuite) and multi-product platforms.
- Clear spatial separation between strategic routing (Top) and operational tasks (Left).

**Live demo variant:** `Default`
