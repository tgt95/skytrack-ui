# Creative knowledge routing

Use this folder for marketing, graphic-design, and art-direction guidance. Load only the relevant
guide when the task needs it; ordinary component implementation does not need this folder.

- [Creative direction](creative-direction.md): audience, narrative, references, visual direction,
  assets, motion, and quality review.
The consuming workspace owns task procedure, execution modes, and checkpoints. This folder provides
creative expertise only; it does not prescribe the full delivery workflow.
