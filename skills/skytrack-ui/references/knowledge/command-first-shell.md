## Overview

Minimalist UI architecture centering user interaction around an omnipresent search bar and command palette triggered by `Cmd+K`.

## Usage

- Developer tools (Vercel, Linear), headless CMS, and power-user SaaS.
- Unlocks keyboard-only execution velocity across actions and navigation.

**Live demo variant:** `Default`
