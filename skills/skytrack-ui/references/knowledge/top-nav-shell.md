# Top Navigation Shell

> Full-width top navigation maximizing horizontal screen real estate for dashboards and analytics.

- Package version: `0.1.5`
- Showcase demo id: `top-nav-shell`

## Overview

All primary navigation is placed horizontally in the top bar, liberating 100% of viewport width for full-bleed charts, metrics, and data grids.

## Usage

- Business intelligence, analytics reporting, and single-module B2B SaaS.
- Combines with a contextual subheader for date-range filtering and exports.

**Live demo variant:** `Default`
